# VoicePaste

[English](README.md) · **Русский**

Голосовой ввод для Windows, который работает **полностью на вашем компьютере**. Нажимаете горячую клавишу, говорите, останавливаете запись, и распознанный текст вставляется в то поле, где стоит курсор (браузер, мессенджер, Word, Блокнот, редактор кода). Заодно он остаётся в буфере обмена.

- Русский и английский, в том числе вперемешку в одной фразе.
- Распознавание — модель [Whisper](https://github.com/ggml-org/whisper.cpp), локально. Никаких облаков, аккаунтов и подписок.
- Две горячие клавиши одновременно: «переключатель» и «удержание».
- Иконка в трее, индикатор записи поверх окон, окно настроек.

## Скачать

Готовые сборки лежат на странице **[Releases](../../releases)**. К каждому релизу приложены два архива и файл `SHA256SUMS.txt` с контрольными суммами.

| Пакет | Для чего | Скорость |
|---|---|---|
| `VoicePaste-…-nvidia` | Видеокарта **NVIDIA RTX 40** (4050–4090) и свежий драйвер | очень быстро, секунды речи распознаются за доли секунды |
| `VoicePaste-…-cpu` | Любой компьютер с процессором, поддерживающим AVX2 (почти все, выпущенные с 2013–2015 года), видеокарта не нужна | заметно медленнее: на модели `Small` фраза обрабатывается за несколько секунд, на `Large turbo` — около 15 секунд. По умолчанию выбрана `Small` |

Если процессор слишком старый (без AVX2), версия `cpu` при запуске скажет об этом в окне и закроется. Часть бюджетных Celeron и Pentium тоже без AVX2.

Версия NVIDIA собрана только под RTX 40. На других видеокартах (GTX, RTX 20/30/50, AMD) она не запустится: берите версию `cpu`. Если нужна другая видеокарта, смотрите раздел «Сборка из исходников».

Требования: Windows 10 или 11 (64 бита), микрофон. Права администратора не нужны.

## Установка

1. Распакуйте архив в любую папку (например, `C:\Programs\VoicePaste`). Все файлы из архива должны лежать рядом.
2. Запустите `voicepaste.exe`. В трее (возле часов) появится иконка. Она **жёлтая**, пока загружается модель, **серая**, когда всё готово, **красная** во время записи.
3. Модель Whisper (файл с распознаванием речи) в архив не входит, потому что она весит от 190 МБ до 1,6 ГБ. Скачайте её одним из способов:
   - правый клик по иконке → **Настройки…** → группа «Распознавание» → **Скачать** рядом с «Large v3 turbo (q5_0)» (575 МБ, рекомендуется). Скачивание идёт с huggingface.co и начинается только по вашей кнопке;
   - либо положите файл `.bin` в папку моделей (правый клик по иконке → «Открыть папку моделей») и выберите его в настройках.
4. Нажмите **Сохранить** в настройках, и можно диктовать.

## Как пользоваться

| Клавиши по умолчанию | Что делают |
|---|---|
| `Ctrl+Alt+D` — переключатель | нажали → пошла запись; нажали ещё раз → остановилась и распозналась |
| `Ctrl+Alt+S` — удержание | держите → идёт запись; отпустили → остановилась и распозналась |

Запись останавливает та клавиша, которой вы её начали. Слишком короткая запись (меньше 0,3 с) и запись без речи ничего не вставляют, и вы услышите сигнал ошибки. Обе клавиши меняются в настройках (кнопка «Задать» и нажмите нужное сочетание); любую можно отключить, очистив поле. Сочетание должно содержать Ctrl, Alt, Shift или Win либо быть клавишей F1–F24.

### Настройки (трей → «Настройки…»)

- **Горячие клавиши**: обе клавиши, проверка «занято другим приложением».
- **Микрофон**: выбор устройства и шкала уровня («Проверить»).
- **Распознавание**: модель (с кнопкой «Скачать»), язык, точность, использование видеокарты, подсказка для модели (можно вписать имена и термины, которые она часто путает).
- **Вставка**: вставлять ли текст в поле или только в буфер обмена; способ вставки; пробел после текста; убирать точку в конце; **начинать с маленькой буквы**; **нажимать Enter после вставки** (удобно, чтобы сразу отправлять сообщение в чате).
- **Интерфейс**: индикатор записи, звуки и их громкость, запуск вместе с Windows.

Изменения применяются сразу, перезапускать программу не нужно. Внизу окна виден журнал работы.

### Файлы программы

Всё лежит в `%APPDATA%\VoicePaste\`:

- `config.toml` — настройки (с комментариями; можно править руками, программа подхватит изменения);
- `models\` — модели Whisper;
- `logs\` — журнал (текст, который вы продиктовали, в журнал **не** записывается).

## Приватность

- Распознавание идёт на вашем компьютере. Звук не отправляется никуда и не сохраняется на диск.
- Единственное обращение к интернету — скачивание модели с huggingface.co, и только после нажатия «Скачать». Телеметрии, обновлений и аккаунтов нет.

## Известные ограничения

- **Окна, запущенные от имени администратора** (например, диспетчер задач или программы, запущенные «от администратора»): Windows не позволяет обычной программе нажимать в них клавиши. Текст при этом всё равно попадёт в буфер обмена, и его можно вставить вручную через `Ctrl+V`.
- Часть программ блокирует вставку. Тогда в настройках выберите способ вставки «по буквам» (медленнее). Для консолей, где `Ctrl+V` не работает, есть `Shift+Insert`.
- Сочетание `Ctrl+Alt+Space` занимает приложение Claude, поэтому по умолчанию используются `Ctrl+Alt+D` и `Ctrl+Alt+S`. Если выбранное сочетание занято другой программой, иконка в трее станет оранжевой с подсказкой, а окно настроек предупредит заранее.
- Модель иногда ошибается в именах и редких терминах. Помогает поле «Подсказка для модели» в настройках.
- Перевод речи на английский пока не реализован (планируется отдельной версией).

## Если что-то не работает

| Что видно | Что делать |
|---|---|
| Иконка оранжевая | Наведите курсор: подсказка скажет причину (занято сочетание, нет файла модели, ошибка в `config.toml`) |
| «model file not found» | Скачайте модель в настройках или положите `.bin` в папку моделей |
| Нет звука при записи/текст не распознаётся | В настройках выберите правильный микрофон и проверьте уровень кнопкой «Проверить» |
| Версия NVIDIA не запускается | Нужна RTX 40 и актуальный драйвер NVIDIA; иначе используйте версию `cpu` |
| Хочется посмотреть, что происходит | Правый клик по иконке → «Открыть папку логов» |

## Сборка из исходников

Нужно: Rust (stable, MSVC), Visual Studio Build Tools с компонентом C++, CMake, LLVM (clang), а для версии NVIDIA ещё CUDA Toolkit 13. Подробный план разработки — в [AGENTS.md](AGENTS.md).

```powershell
. .\env.ps1                                       # переменные окружения для CUDA и LLVM (поправьте пути под себя)
cargo test --release                              # проверки
cargo run --release                               # консольная сборка для разработки (логи на экране)

.\scripts\build-release.ps1 -Variant nvidia       # exe без консоли, CUDA для RTX 40 (sm_89)
.\scripts\build-release.ps1 -Variant cpu          # exe без консоли, без видеокарты
.\scripts\package.ps1                             # папки и zip-архивы в dist\
```

Для другой видеокарты NVIDIA замените `CMAKE_CUDA_ARCHITECTURES` в `scripts\build-release.ps1` (например, `86` для RTX 30, `75` для GTX 16 и RTX 20, `120a` для RTX 50) и пересоберите whisper.cpp (первая сборка CUDA занимает около десяти минут). Сборки идут с пониженным приоритетом и ограничением потоков, чтобы компьютер оставался отзывчивым.

Как выпустить релиз на GitHub — в [docs/RELEASING.md](docs/RELEASING.md).

Полезные ключи командной строки для отладки: `--list-devices`, `--device <часть имени>`, `--model <путь>`, `--dump-audio <папка>`, `--transcribe-file <wav>`, `--test-mic`, `--demo-overlay`.

## Лицензии сторонних компонентов

- [whisper.cpp](https://github.com/ggml-org/whisper.cpp) и модели [Whisper](https://github.com/openai/whisper) — MIT.
- Библиотеки Rust (egui, winit, cpal, tray-icon и другие) — MIT и/или Apache-2.0.
- Библиотеки NVIDIA CUDA (`cublas64_13.dll`, `cublasLt64_13.dll`, `cudart64_13.dll`) в пакете NVIDIA распространяются по [лицензии NVIDIA CUDA Toolkit](https://docs.nvidia.com/cuda/eula/) (они входят в список файлов, разрешённых к распространению вместе с приложением).
- Библиотеки среды выполнения Visual C++ (`msvcp140.dll`, `vcruntime140*.dll`) — распространяемые компоненты Microsoft.

Библиотеки NVIDIA CUDA входят **только в архив NVIDIA** на странице релизов и не хранятся в этом репозитории.
